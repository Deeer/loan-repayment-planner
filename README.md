# 房贷提前还款规划器

这是一个无外部依赖的静态页面，入口为 `index.html`，可直接本地打开，也可以通过 GitHub Pages 发布。

## GitHub Pages 发布

1. 将本目录内容推送到一个独立 GitHub 仓库。
2. 在仓库的 **Settings → Pages** 中，将发布来源设为 **Deploy from a branch**。
3. 选择 `main` 分支和 `/(root)`，保存后等待 GitHub Pages 完成发布。

页面内置的是虚构演示数据，不含你的真实贷款余额。网页会公开访问；输入数据仅在浏览器本地计算，不会上传。仓库源代码仍可保持私有。
